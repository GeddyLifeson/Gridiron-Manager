# IP and marks review, 2026-11-26

Not legal advice. Notes for the lawyer who reviews the release (bible A6.5.1, release gate item 5).

## How this was checked

1. The release gate's own scans (`npx tsx scripts/release/gate.ts --report-only`) on main at 864411d: A6.2.2 mark scan, real-name scan, research-path and per-person record checks, asset licence register.
2. A file search of the repository for images, fonts, audio and PDFs.
3. A separate text search of shipped source and data for the 32 pro nicknames and for league, event, trophy and broadcast marks (Super Bowl, Pro Bowl, Lombardi, Heisman, the bowl names, the conference names, Monday Night Football and others).

## What is clean

- Logos, uniforms, photos: none. The only images are the desktop app icons (a plain green field with white yard lines, added in the phase 0 commit 7161a7f2; no mark or logo) and four formation diagrams (SVG dots and lines in `packages/football-content/data/starter/formations/`).
- Fonts: none bundled; the browser build uses the system font.
- Music and sound: four menu loops in `assets/music/`, original compositions rendered with the MIT-licensed MuseScore General soundfont; every file has a Verified row in `assets/LICENSES.json` and the checker passes. Crowd and game sounds are synthesised in code. No broadcast music, no NFL Films music, no recorded voices.
- Team identities: generated; the generator checks a blocked-terms list.
- Open-source licences: 493 shipped packages, all permissive (MIT, Apache-2.0, BSD, ISC, Zlib, Unicode-3.0, Unlicense) apart from 7 MPL-2.0 crates in the desktop shell (file-level copyleft: fine to ship unmodified in a closed program, but their source must stay available, which crates.io provides). No GPL or LGPL-only component. Full list: `THIRD_PARTY_NOTICES.md`.

## Flags for review (not changed in this PR)

1. **Real league and conference names in player-facing glossary text.** The gate's mark scan reports 573 hits in shipped files: NFL 287, NCAA 230, FBS 13, Super Bowl 5, FCS 4, the power-conference names (SEC, ACC, Big Ten, Big 12, Pac-12) 3 each, College Football Playoff 3, Pro Bowl 3, and 10 real team names (for example "Philadelphia Eagles", "New Orleans Saints", "Las Vegas Raiders", "Texas Longhorns"). Almost all are in `packages/football-content/data/glossary/` (terms-rules 388, terms-college 67, terms-special-teams 31, terms-front-office 15). Most are descriptive ("under NFL rules"), which is probably nominative use, but A6.1.1 says league, event and trophy names in the game are generated, and the gate fails on them. Decide: allow descriptive uses in the glossary (record them in `scripts/release/data/allowed.json`), or reword to the game's own league names.
2. **Real people's names in player-facing glossary text.** 38 hits: coaches credited for schemes (Dick LeBeau, Pete Carroll, Wade Phillips, Dan Quinn, Kyle Shanahan), a current college player (Diego Pavia) and source authors in `football-content/src/*/sources*.ts`. Naming a coach as the origin of a scheme is factual, but A6.3 keeps real people out of the shipped game. Decide the same way as item 1.
3. **Rule book text in the repository.** `facts/rule.json` holds 2,264 quotations from the 2026 NFL and NCAA rule books, about 315,000 characters in total (longest 451). It is research data, not bundled into the game (nothing in the browser build imports it), but if the GitHub repository itself is made public, that much verbatim rule book text is a copyright question (A6.1.1 marks it "a question for the lawyer"). Options: keep the repository private and ship only the build, or cut the quotes to citations (rule, section, article) before publishing the source.
4. **Per-person research record shipped.** The gate finds `packages/engine-game/src/flow/pace-facts.json` byte-identical to the research file `research/pace/pace-facts.json` (A6.4.1 item 3).
5. **Blocked-terms list is PROVISIONAL.** Its entries have not been read from logged public sources yet, so even a clean mark scan cannot pass the gate.
6. **"Gridiron Manager" name.** No trademark search has been done for the game's own title. A clearance search is worth doing before a commercial release.
7. **Copyright holder.** The notices name the GitHub owner "GeddyLifeson". For a commercial release the holder should be the legal name of the person or company that will sell the game; change `LICENSE`, `LEGAL.md` and `packages/app-ui/src/legal/about.ts` together (a test keeps them in step).
